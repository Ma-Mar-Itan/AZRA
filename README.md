# AZRA Systems website

A dependency-free static website designed for GitHub Pages.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the publishing branch (usually `main`) and the `/ (root)` folder.
5. Save. GitHub will provide the public URL after deployment.

All asset paths are relative, so the site works from either a user/organization
domain or a repository subpath.
